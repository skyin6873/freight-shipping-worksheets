# Freight Shipping Worksheets

Reusable CSV worksheets, shipment evidence checklists and a Python packed-freight density calculator.

See [worksheets](worksheets/README.md) for files, formulas, provenance and usage.

The accompanying explanations are maintained at [Freight Class Desk](https://freightclassdesk.com/).

Hypothetical example inputs are explicitly labeled; blank templates are recordkeeping aids, not observed shipment data or repair specifications.
