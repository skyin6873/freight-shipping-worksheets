# Pallet disposition fields

This record is not a repair specification, load rating or permission to reuse a damaged pallet.

| Field | Record |
|---|---|
| record_id | Local record identifier |
| observed_defect | Observed condition; avoid inferring a rating |
| photo_reference | Evidence file or reference |
| quarantine_location | Where the pallet is isolated |
| owner | Identified owner or unknown |
| repair_authority | Party authorized under the applicable system, or unresolved |
| specification_and_component | Applicable specification and affected component |
| supplier_description | Supplier wording, retained separately from acceptance |
| proposed_load_and_support | Intended application, load and support arrangement |
| repair_evidence | Evidence of completed work, if any |
| acceptance_by | Identified reviewer accepting the intended application |
| disposition | Recorded decision; the blank record starts on hold |
| decision_basis | Evidence and rule supporting the decision |
| history | Earlier decisions and changes |
